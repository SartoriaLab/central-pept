Todos os números deste guia vêm das fontes abaixo. Em cada uma está indicado para que ela foi usada. Quando só o resumo do artigo estava disponível, isso está dito. As revisões de Loren Pickart foram usadas como mapa, e os dados foram conferidos no estudo original sempre que possível: Pickart descobriu o GHK e assina os artigos com o endereço de uma empresa de cosméticos com peptídeos de cobre, embora os artigos declarem não haver conflito de interesse.
